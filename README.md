A simple 3D raycast written in C++ using SDL3 and GLM libraries.

Intended to be compiled with Visual Studio 2026.

# General controls
F11 - toggle fullscreen mode

Escape - quit

# Editor controls

  Left mouse button - place a wall
  
  Right mouse button - remove the wall
  
  Right shift + R - reset the map

  F - toggle rays

  Mouse wheel - rotate rays
  
  G - switch to gameplay mode

  P - set the player spawn

# Gameplay controls

  WASD - move around

  E - rotate clockwise

  Q - rotate counterclockwise

  G - switch to editor mode
